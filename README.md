# Piyush Kumar Rai — Developer Portfolio

A responsive personal portfolio website presenting my background, technical interests, selected work, and contact information.

## What's included

- `index.html` — portfolio page and content sections.
- `css/` — stylesheets and visual presentation.
- `js/script.js` — client-side interactions.
- `resume.pdf` — downloadable resume currently included with the site.
- `generate_resume.py` — Python utility for generating a resume document.

## Run locally

This is a static website. Clone the repository and open `index.html` in a browser, or serve the repository directory with any simple static HTTP server. External fonts and icon assets are loaded from third-party CDNs, so an internet connection is needed for those assets.

## Deployment

The site can be hosted on any static hosting provider. Configure the published root to the repository directory and verify that the resume link, navigation, responsive layout, and contact links work on the deployed URL.

## Before publishing

Review the contact details and resume in the repository before making the site public. Keep personal information current and remove any details you do not want indexed by search engines.
